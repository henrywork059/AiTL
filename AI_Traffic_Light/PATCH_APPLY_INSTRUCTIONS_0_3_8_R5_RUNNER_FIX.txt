Purpose

- Prevent update_test_run.ps1 from auto-running that hardware CLI without arguments.
- Preserve automated coverage with scripts/test_camera_transport_benchmark_logic.py, which exercises diagnosis/ranking/evidence logic without hardware.

Recommended apply workflow
1. Extract the ZIP and upload/commit the changed files as one atomic update to GitHub main (or commit the overlay locally).

3. On the Windows PC, from the repository root:
   git status --short
   git pull --ff-only origin main
4. Re-run the normal helper:
   .\AI_Traffic_Light\scripts\update_test_run.ps1 -SkipUpdate

- test_camera_transport_benchmark.py is reported as excluded from the automatic no-hardware regression sweep.
- test_camera_transport_benchmark_logic.py runs automatically and should print PASS lines.
- The normal frontend build, live backend smoke, and PC Studio startup continue afterward if all other checks pass.

Run the physical benchmark separately after flashing the R5 benchmark firmware:

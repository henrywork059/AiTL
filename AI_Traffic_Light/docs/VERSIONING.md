# Versioning

Use simple version tags:

```text
v0.1.0  initial skeleton
v0.2.0  mock GUI connected to mock API
v0.3.0  webcam/video input
v0.4.0  object detection
v0.5.0  zone counting and signal logic
```

Recommended zip naming:

```text
AI_Traffic_Light_v0_1_0.zip
AI_Traffic_Light_v0_2_0_patch.zip
AI_Traffic_Light_v0_3_0_patch.zip
```

Commit message examples:

```text
Add initial project skeleton
Add mock live view API
Add detection viewer placeholder
Add zone schema
Add ESP-CAM firmware placeholder
```

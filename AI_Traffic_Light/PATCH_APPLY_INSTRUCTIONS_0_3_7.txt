AiTL V037 R6 patch application
===============================

Version remains 0_3_7. Do not change passed_baseline (0_2_4).

Normal GitHub workflow
----------------------
1. Extract the changed-files ZIP.
2. Upload/commit the extracted `AI_Traffic_Light/...` files to GitHub main, preserving paths.
3. On the PC, from `AI_Traffic_Light`, run:

   .\scripts\update_test_run.ps1

4. Do not use `-SkipUpdate` when the patch exists only on GitHub.
5. Flash the standalone V037 `.ino` to the AI Thinker ESP32-CAM. Keep your existing Wi-Fi credentials/secrets.
6. Serial Monitor at 115200 should show:

   AiTL V037 R6 quality-preserving TCP ESP32-CAM node

7. Start with QVGA / JPEG 24 / 5–15 FPS and verify `fixed=yes` plus RSSI/BSSID/channel telemetry.

Manual local overlay workflow
-----------------------------
Only if these changed files were deliberately overlaid into the local tracked working tree before GitHub contains them, validate with the established manual-overlay method rather than performing a normal pull across tracked edits.

R6 does not rewrite runtime datasets, models, saved camera profiles, or other user-generated state.

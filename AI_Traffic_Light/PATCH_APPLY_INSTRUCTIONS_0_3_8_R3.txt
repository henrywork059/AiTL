AiTL 0_3_8 R3 — camera transport isolation test (diagnostic-only)

This overlay adds a temporary diagnostic firmware sketch and a PC test runner. It does not replace normal V037 production streaming and does not change passed_baseline.

Apply from the repository root:
1. Extract this ZIP into the repository root so paths merge under AI_Traffic_Light/.
2. Confirm the six files in PATCH_MANIFEST_0_3_8_R3.txt exist.
3. Run:
   python .\AI_Traffic_Light\scripts\test_camera_transport_isolation.py --help
4. Flash AI_Traffic_Light\apps\device-camera\esp32-cam\arduino\AiTL_ESP32_CAM_TRANSPORT_DIAG\AiTL_ESP32_CAM_TRANSPORT_DIAG.ino
5. Run the physical test using the ESP IP.
6. Reflash normal V037 firmware after collecting the report.

No runtime/user dataset/model files are modified by this overlay.

AiTL 0_3_8 R5 Camera Transport Benchmark - apply/test instructions

Release state
- Keep VERSION at 0_3_8. This is a same-candidate diagnostic revision because 0_3_8 is still unaccepted.
- Do not change passed_baseline; 0_2_4 remains the owner-confirmed passed baseline.
- This package is diagnostic-only and does not replace the normal production camera transport.

Apply
1. Extract this ZIP over the repository root so every file lands under AI_Traffic_Light/.
2. In the Arduino diagnostic sketch folder, copy secrets.example.h to secrets.h and enter the 2.4 GHz Wi-Fi credentials.
3. Flash AiTL_ESP32_CAM_TRANSPORT_DIAG.ino with Arduino IDE.
4. Open Serial Monitor at 115200 and note the ESP IP.

Run
python .\AI_Traffic_Light\scripts\test_camera_transport_benchmark.py --host <ESP_IP> --frames 8 --fps 5 --chunk-sweep --environment-label home-router

The console now shows the current benchmark section/test plus per-frame progress. The report camera_transport_benchmark.json uses schema_version 3 and contains detailed before/during/after telemetry and A/B evidence for later analysis.

Optional environment comparison
Run the same benchmark with different --output and --environment-label values, then:
python .\AI_Traffic_Light\scripts\compare_camera_transport_reports.py .\home.json .\hotspot.json

After the diagnostic
Restore/reflash the normal V037 production firmware before normal PC Studio operation. Do not treat a benchmark winner as a production change until the owner reviews the result and the corresponding production patch is implemented/tested.

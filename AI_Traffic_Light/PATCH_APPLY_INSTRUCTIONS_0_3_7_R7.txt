AiTL V037 R7 control-connection reliability repair

This is a same-candidate V037 repair. Project version remains 0_3_7 and passed_baseline remains 0_2_4.

Purpose
- Fix intermittent PC Studio Connect 502 failures while the R6 ESP remains Wi-Fi associated.
- Serialize PC -> ESP HTTP control traffic per camera session.
- Retry transient socket/timeout control failures up to three times.
- Do not retry deterministic HTTP/protocol errors.
- Keep the R6 ESP32 firmware and ATL1 TCP JPEG data plane unchanged.

Apply
1. Upload/extract the patch members to GitHub main preserving the leading AI_Traffic_Light/ paths.
2. Do NOT flash a new ESP sketch for R7; keep V037 R6 quality-preserving TCP firmware installed.
3. On the PC run the normal updater from AI_Traffic_Light (no -SkipUpdate):

   .\scripts\update_test_run.ps1

4. In Camera Sources, Save/Connect to the ESP IP and then Start Stream.

Expected behavior
- A single transient /status timeout should no longer immediately return 502.
- Backend logs may show 'Transient ESP control request failed; retrying' before a successful Connect.
- Background status polling must not overlap Connect/Start/Stop/recovery control requests to the same ESP.

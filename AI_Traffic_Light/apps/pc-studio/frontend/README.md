# PC Studio Frontend

React/Vite placeholder GUI for the AI Traffic Light PC Studio App.

## Run

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Current state

This frontend uses mock data and placeholder SVG-style layout. It is intended for fast GUI development with hot reload.
